# Changelog

Все значимые изменения проекта документируются в этом файле.

Формат — [Keep a Changelog 1.0.0](https://keepachangelog.com/ru/1.0.0/),

## [1.0.2] — 2026-09-20

### Исправлено

- **Провайдер codex-cli больше не затирает MCP-серверы из профиля.** Ключ
  `-c mcp_servers={}` подставлялся всегда и обнулял весь список серверов
  профиля `CODEX_HOME`; точечные ключи `mcp_servers.<имя>.url`, добавленные
  следом, его уже не восстанавливали, и агенту на codex нельзя было дать ни
  одного инструмента. Теперь обнуление ставится только тем агентам, которые
  своих серверов не приносят.
- **Провайдер codex-cli передаёт рабочий каталог вызова.** `cwd_template`
  агента не передавался вовсе, и codex работал в каталоге службы. Теперь
  каталог уходит ключом `-C`, и песочница `workspace-write` ограничивает
  запись каталогом задания.
- **Сторож повторов не обрывает ход на одной повторяющейся строке.** Шесть
  вхождений одной длинной строки в пределах 5000 знаков считались петлёй, и
  исполнитель останавливался на первом ходу, описывая структуру с однотипными
  атрибутами `serde`. Теперь порог «подряд» применяется, только если до него
  встретились минимум две разные строки; одиночную строку ловит порог за весь
  ход.

## [1.0.1] — 2026-09-18

### Исправлено

- **Ответ модели с пояснением перед рамкой ```json больше не отвергается.**
  Рамка снималась только с начала ответа, поэтому строка вроде «Проверил три
  места» перед JSON приводила к пометке вызова «неполный», и готовая работа
  агента пропадала (случай повторялся у DeepSeek Flash и у Opus). Теперь рамка
  находится в любом месте ответа; если рамки нет вовсе — берётся кусок от первой
  открывающей скобки до последней закрывающей; если ничего похожего на JSON нет
  — возвращается сам ответ.
